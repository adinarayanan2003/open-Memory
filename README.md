# open-Memory

Spec and system design for an agentic company memory system.

The project explores a universal memory layer for teams: connectors ingest company sources, agents construct a typed and evidence-backed knowledge graph, retrieval is handled through agentic planning, and uncertain knowledge is routed back to humans through ask-back workflows.
